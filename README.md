# PulmoHTapAlgérie 🫁
منصة متكاملة لمتابعة مرضى ارتفاع ضغط الدم الرئوي في الجزائر.

## 🎯 نظرة عامة
تطبيق Full-Stack مخصص لتوحيد حسابات وسجلات المرضى والأطباء والمختصين في الجزائر، لتسهيل إدارة المواعيد، السجلات الطبية، والمتابعة الصحية عبر 58 ولاية جزائرية.

## ✨ المميزات الرئيسية
- **نظام حسابات موحد (Unified Accounts)** لـ 9 أنواع من المستخدمين.
- **إدارة المواعيد (Appointments)** للمرضى والأطباء.
- **سجلات طبية إلكترونية (EMR)** مركزية وآمنة.
- **تأكيد الهوية عبر البريد (Email Verification)** واستعادة كلمات المرور.
- **حماية متقدمة** باستخدام JWT و Security Cookies.
- **دعم اللغة العربية** وتصميم متوافق مع كافة الأجهزة (Mobile-First).

## 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية**: React (Vite) + Tailwind CSS v4.
- **الخادم الخلفي**: Node.js + Express + Zod.
- **قاعدة البيانات**: PostgreSQL (Supabase) + Prisma ORM.

## 🚀 الأوامر الأساسية
من الجذر الرئيسي للمشروع يمكنك تشغيل:
- `npm run dev`: تشغيل الخادم الخلفي والأمامي معاً (Concurrently).
- `npm run build`: بناء الواجهة الأمامية للإنتاج.

اقرأ ملف [INSTALLATION_GUIDE.md](./INSTALLATION_GUIDE.md) لمزيد من التفاصيل حول التثبيت.
